Other tabs (example behavior):
Evidence — after you click a row above, this can show source refs for that suggestion.
Chat — ask questions about the report in a small thread.
Activity — other mission/report activity text.

Empty state: If the pipeline hasn’t produced structured edits (or they’re all applied), the Proposed changes list is simply empty — same panel, no rows. That is normal and does not mean the app is in a different “generation mode”; generation is triggered elsewhere (e.g. Update).
